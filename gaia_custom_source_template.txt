Gaia custom map source URL template

After GitHub Pages is enabled, use this URL in Gaia:

https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPO_NAME/tiles/{z}/{x}/{y}.png

Settings:
- Type: TMS or custom tile URL
- Minimum zoom: 13
- Maximum zoom: 17
- Format: PNG
- Overlay: yes, if Gaia asks
